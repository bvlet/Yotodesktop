# UI guidelines

## Interface design

- Use the existing design tokens and component patterns so related controls remain visually consistent.
- Keep hierarchy clear: primary actions should be easy to find, while secondary actions should not compete with the current task.
- Use Lucide for all interface icons; do not use text glyphs, emoji, or custom-drawn UI icons.
- Give every interface icon strong contrast against its background in its default and hover states.

## Interaction design

- Every interactive, clickable element must have a visible hover state. This includes buttons, menu items, tabs, and clickable cards or rows.
